# Rabieta Virtual Office

RVO coordinates evidence-backed changes to the Rabieta table service.

Loop: OBJECTIVE → PLAN → TASKS → EXECUTION → TEST → AUDIT → RETRY / ESCALATE → RESULT.

See [state](RVO_STATE.md), [tasks](TASKS.md), [decisions](DECISIONS.md),
[claims](CLAIMS.md), and [proof](PROOF/README.md). Application operation remains
documented in README-DEPLOY.md. This work does not authorize deployment or merge.

Validation: `npm ci`, `git diff --check`, `npm run check`.
